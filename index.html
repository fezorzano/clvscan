Instrucciones

01. Regístrate en the-odds-api.com → obtén tu API key gratuita.

02. Crea un nuevo Google Sheets → Extensiones → Apps Script.

03. Pega el contenido de CLV_System_AppsScript.js en el editor.

04. Reemplaza TU_API_KEY_AQUI y TU_EMAIL@gmail.com en CONFIG.

05. Ejecuta configurarTrigger() una sola vez → escaneo automático cada hora activo.

06. En Apps Script: Implementar → Nueva implementación → Aplicación web. Ejecutar como: Yo. Acceso: Cualquier persona. Copia la URL generada.

07. Pega esa URL en la constante WEB_APP_URL al inicio del JS de este dashboard.

08. Listo. Al tocar "Registrar apuesta" en una card, los datos van directo a tu Google Sheets.
